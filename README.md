# ALTIORA Canton Fair Map

Mobile-first веб-приложение для обхода 64 подтверждённых точек Canton Fair Phase 1.

## Данные

- Источник: `data/Canton_Fair_Phase1_FULL_64_POINTS_MASTER.xlsx`, лист **FULL MASTER LIST** (64 строки, 19 колонок).
- Импорт: `npm run import:excel` (нужен Python 3 + `openpyxl`) → `src/data/points.json`.
  Все колонки сохраняются дословно (поле `raw`), плюс разобранный список Booth и Hall.
- Hall и Booth из Excel — authoritative. Координаты стендов не выдумываются: GPS используется только как
  подсказка, текущий Hall выбирается вручную (Hall Selector).

## Функции

- **Далее** — следующая рекомендованная точка: сначала Priority A, потом B; внутри приоритета — точки текущего Hall,
  затем ближайшие по номеру Hall. После «Посетила» текущий Hall обновляется и сразу предлагается следующая точка (с «Отменить»).
- Статусы: Посетила, Получить цену, Follow-up, Пропустить, Контакт получен + заметки. Хранятся в `localStorage`.
- **Список** — поиск по компании, товару, Hall, Booth; фильтры по приоритету, Hall, направлению, группе карты, статусу.
- **Маршрут** — точки сгруппированы по Hall, павильоны упорядочены от текущего к ближайшему по номеру.
- **Статистика** — всего, посещено, осталось, Priority A осталось, контакты, Follow-up; экспорт CSV, резервная копия JSON.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # production-сборка в dist/
```

## Vercel

Импортируйте репозиторий в Vercel — framework **Vite** определяется автоматически (`vercel.json`):
build `npm run build`, output `dist`. Backend и переменные окружения не нужны.
